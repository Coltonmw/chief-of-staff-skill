# Chief of Staff skill

A free, reusable Chief of Staff skill for AI agents that work for a small firm's principal. It helps an agent keep projects moving, run meetings, own weekly reporting, and carry client conversations up to the point of commitment, while leaving every price, term and send decision with the principal.
